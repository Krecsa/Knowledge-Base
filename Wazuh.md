# Wazuh: Развертывание и мониторинг

Wazuh - это бесплатная open-source платформа для мониторинга безопасности (SIEM и XDR). Она собирает логи, проверяет целостность файлов, ищет уязвимости и анализирует события.

## Архитектура (из чего состоит)
Wazuh состоит из трех основных компонентов. При установке «All-in-One» они все стоят на одной виртуалке.

* **Wazuh Manager:** «Мозг» системы. Он принимает данные от агентов, анализирует их по правилам (rules) и генерирует алерты.
* **Wazuh Indexer:** База данных (на базе OpenSearch/Elastic). Хранит все логи и события.
* **Wazuh Dashboard:** Веб-интерфейс (порт 443). Через него мы смотрим графики, ищем события и управляем агентами.

## Установка (в изолированной среде)
Для безопасного изучения мы развернули Wazuh на Ubuntu в Hyper-V.

* **Изоляция:** Создали внутренний (Internal) коммутатор в Hyper-V и настроили NAT, чтобы виртуалка имела доступ в интернет для скачивания пакетов, но не была видна из домашней сети.
* **Установка:** Использовали официальный скрипт с флагом `-a` (All-in-One). Команда для запуска: `curl -sO https://packages.wazuh.com/4.14/wazuh-install.sh && sudo bash ./wazuh-install.sh -a`
* **Пароли:** После установки логин и пароль администратора сохраняются в архиве. Достать их можно командой: `sudo tar -O -xvf wazuh-install-files.tar wazuh-install-files/wazuh-passwords.txt`

## Как работает мониторинг (Агенты)
Wazuh не мониторит систему сам по себе. На устройство (Windows, Linux, сервер) нужно установить **Агент** - маленькую программу, которая собирает логи и отправляет их на Manager.

* **Развертывание агента:** В дашборде (Agents management -> Deploy new agent) генерируется команда для установки под нужную ОС.
* **Статус агента:** Если агент работает нормально, в веб-интерфейсе он горит зеленым (Active). Если нет - красным (Disconnected).

## Ключевые модули и возможности Wazuh
Wazuh - это не только сбор логов. В него встроено несколько мощных модулей безопасности:

### File Integrity Monitoring (FIM) - Контроль целостности файлов
Модуль следит за изменениями важных файлов и директорий. Он создает «базовую линию» (baseline) с контрольными суммами файлов. Если файл изменен, удален или добавлен, Wazuh сравнивает текущее состояние с базой и выдает алерт. Это критически важно для обнаружения несанкционированных изменений в конфигах (например, в `/etc/passwd` или `sshd_config`). На Windows модуль мониторит и реестр.

### Security Configuration Assessment (SCA) - Оценка конфигурации
Этот модуль сканирует систему и сравнивает её настройки с эталонными стандартами безопасности (например, CIS Benchmarks). Он проверяет, отключен ли вход по паролю для root, настроены ли определенные параметры ядра и т.д. В дашборде ты видишь процент соответствия (Score) и список проваленных проверок с рекомендациями по исправлению (Remediation).

### Vulnerability Detection - Обнаружение уязвимостей
Агент собирает список установленного ПО (пакеты) и отправляет его на сервер. Wazuh сверяет этот список с базой уязвимостей (CVE) и показывает, какие программы на твоей машине имеют известные дыры. Для каждой уязвимости виден уровень критичности (CVSS) и рекомендации по обновлению.

### Threat Hunting (Анализ логов и правил)
Это ядро SIEM. Wazuh собирает логи со всех агентов, разбирает их через декодеры (вытаскивает IP, имена пользователей, события) и прогоняет через правила (rules). Если событие совпало с правилом (например, «успешный вход», «5 неудачных попыток пароля»), генерируется алерт. В разделе Threat Hunting ты можешь искать по всем событиям, фильтровать по уровню критичности и строить сложные запросы.

### Active Response (Активное реагирование)
Это автоматизация защиты. Wazuh может не просто «заорать» об атаке, но и выполнить скрипт. Например, при обнаружении брутфорса SSH он автоматически запускает `firewall-drop` и блокирует IP атакующего через `iptables` на 180 секунд. Это снижает нагрузку на аналитика.

## Что смотреть в Wazuh Dashboard (Для аналитика)
* **Threat Hunting:** Главный раздел для поиска событий. Здесь можно фильтровать логи по уровню критичности (`rule.level >= 7`), искать конкретные IP или имена пользователей.
* **File Integrity Monitoring:** Показывает, какие файлы были изменены, кем и когда.
* **Vulnerability Detection:** Список CVE на твоих хостах.
* **Configuration Assessment:** Оценка защищенности конфигурации (CIS Benchmarks).
* **MITRE ATT&CK:** Wazuh автоматически мапит события на тактики и техники MITRE ATT&CK, что помогает аналитику понимать контекст атаки.

## Практика (Как проверить, что всё работает)
Создаем нового пользователя на виртуалке с Ubuntu (где стоит агент): `sudo useradd -m testuser`. Затем идем в Wazuh Dashboard -> Threat Hunting и ищем событие по слову `testuser` или `useradd`. Если SIEM работает, мы увидим алерт о том, что в системе создан новый пользователь.
