# Инструменты для анализа безопасности (Tools)

В этой папке собраны мои личные скрипты и утилиты для анализа данных, работы с логами и решения задач по информационной безопасности.

**Все скрипты в этой папке предназначены ИСКЛЮЧИТЕЛЬНО для следующих целей:**

1. **Образовательные цели:** Изучение принципов работы веб-приложений, сетевых протоколов и анализа данных.
2. **Соревнования по информационной безопасности (CTF):** Решение задач на официальных площадках (например, Duckerz, HackTheBox, TryHackMe), где применение подобных инструментов разрешено правилами платформы.
3. **Тестирование собственной инфраструктуры:** Анализ логов своих серверов, аудит своих пет-проектов и проверка безопасности систем, которыми вы владеете.

## Как запускать

1. Убедитесь, что установлен Python 3.
2. Откройте терминал (cmd или bash) и перейдите в эту папку: `cd путь/к/папке/tools`
3. Запустите нужный скрипт `python имя_скрипта.py`
