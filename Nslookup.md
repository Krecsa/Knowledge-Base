# Nslookup

`nslookup` (Name Server Lookup) — это утилита командной строки для запросов к DNS-серверам. В SOC она используется для проверки доменов, поиска IP-адресов, выявления подозрительных ресурсов и проверки инфраструктуры (например, куда резолвится домен злоумышленника).

## Как работает DNS-резолв

Когда ты вводишь `nslookup site.com`, утилита отправляет запрос твоему локальному DNS-серверу (обычно это роутер или сервер провайдера). Этот сервер либо знает ответ (из кэша), либо идет спрашивать дальше.

### Рекурсивный и Итеративный запросы

*   **Рекурсивный (Recursive):** Клиент делает один запрос своему DNS-серверу и говорит: «Найди мне IP, я ничего делать не буду». Сервер сам бегает по всему интернету (Root -> .ru -> site.ru) и возвращает готовый ответ.
*   **Итеративный (Iterative):** Клиент сам делает несколько запросов. Спрашивает у Root: «Где .ru?», потом у .ru: «Где site.ru?», потом у site.ru: «Какой IP?».

### Доверенный (Authoritative) vs Недоверенный (Non-authoritative)

*   **Authoritative (Доверенный):** Ответ пришел напрямую от DNS-сервера, который отвечает за эту доменную зону (например, от ns1.yandex.ru). Это самые точные данные.
*   **Non-authoritative (Недоверенный):** Ответ пришел из кэша промежуточного сервера (например, твоего роутера 192.168.0.1). Это значит, что кто-то до тебя уже спрашивал этот домен, и роутер запомнил ответ. Данные могут быть устаревшими (с учетом TTL).

## Основные типы записей

*   **A (Address):** Превращает домен в IPv4-адрес. (Основной запрос).
*   **AAAA:** Превращает домен в IPv6-адрес.
*   **CNAME (Canonical Name):** Показывает, что домен является псевдонимом (алиасом) другого домена.
*   **MX (Mail Exchanger):** Указывает, какие серверы принимают почту для этого домена (полезно для проверки фишинга).
*   **NS (Name Server):** Указывает, какие DNS-серверы являются авторитативными для этой зоны (кто хозяин).
*   **PTR (Pointer):** Обратный запрос. Превращает IP-адрес в доменное имя. В SOC используется для проверки, какому провайдеру/хосту принадлежит IP.
*   **TXT (Text):** Текстовые записи. Часто используются для SPF (защита от подделки почты), верификации домена (Google, Яндекс) и т.д.
*   **SOA (Start of Authority):** Служебная запись с основной информацией о домене (админ, серийный номер, таймауты).

## Как пользоваться в SOC (Практика)

### Проверка подозрительного домена

Если ты видишь в логах подозрительный домен (например, evil-update.com), первым делом проверь его: `nslookup evil-update.com`

Если он резолвится в IP, ты можешь проверить этот IP через Whois (или сервисы типа VirusTotal). Если домен не резолвится — малварь уже мертва (или это домен для C2, который включается только в определенное время).

### Обратный резолв (PTR) для проверки IP

Ты нашла в логах подозрительный IP 95.58.77.9. Нужно понять, что это за хост: `nslookup 95.58.77.9`

Утилита автоматически сделает PTR-запрос. В ответе ты увидишь 95.58.77.9.dynamic.telecom.kz. Это подскажет, что IP принадлежит казахстанскому провайдеру (зона .kz).

### Проверка почтовых записей (MX)

Если расследуешь фишинг, посмотри, откуда реально пришло письмо: `nslookup -type=MX company.com`

Это покажет реальные почтовые серверы компании.

## Синтаксис и трюки

**Общий синтаксис:** `nslookup -type=ТИП домен`

**Важно:** В Windows nslookup капризный. Параметры -type=... должны идти строго перед доменом, иначе он выдаст ошибку «адрес сервера для...».

**Правильно:** `nslookup -type=MX yandex.ru`
**Неправильно:** `nslookup yandex.ru -type=MX`

**Запрос к конкретному DNS-серверу:** Если хочешь спросить не свой роутер, а, например, Google DNS: `nslookup -type=A yandex.ru 8.8.8.8`

## Что важно помнить аналитику

1.  **Кэш (TTL).** Если ты поменял запись на DNS-сервере, она не обновится у всех сразу. Нужно ждать TTL (время жизни записи).
2.  **Nslookup не проверяет репутацию.** Он просто говорит «IP есть». Чтобы понять, что это малварь, нужно проверять IP в VirusTotal или смотреть на домен (например, microsoft-update-security.com — это фишинг).
3.  **Nslookup в Linux работает так же**, как в Windows (если установлен пакет dnsutils). Синтаксис такой же.
