# Windows Event Viewer

Event Viewer (Просмотр событий) — это главный инструмент анализа хоста в Windows.

## Где находится и как открыть

1. Нажать `Win + R`, ввести `eventvwr.msc` и нажать Enter.
2. Или через меню Пуск -> Администрирование -> Просмотр событий.

Основные журналы (слева в дереве):
* **Security (Безопасность)** — главный журнал для ИБ. Входы, процессы, доступ к файлам, изменения политик.
* **System (Система)** — драйверы, службы, перезагрузки.
* **Application (Приложение)** — ошибки программ.
* **PowerShell / Sysmon** — если включены, там логи скриптов и глубокий мониторинг процессов.

## Основные коды событий (Security)

### Аутентификация

**4624 — Успешный вход**
Самый частый код. Показывает, кто и как вошел.
* **Имя учетной записи** — кто вошел.
* **Тип входа (Logon Type)** — ключевое поле:
  * **2** — интерактивный (сел за компьютер).
  * **3** — сетевой (по SMB, с другого хоста).
  * **10** — RDP (удаленный рабочий стол).
* **ИД входа (Logon ID)** — идентификатор сессии (например, `0x5AD03C91`).

**4625 — Неудачный вход**
Каждая неудачная попытка. Если их много подряд с одного IP по одной учетке — это брутфорс.
* Смотреть на **Имя учетной записи** и **Сетевой адрес источника**.

**4634 / 4647 — Выход из системы**
Когда пользователь завершил сессию.

### Процессы

**4688 — Создан новый процесс**
Главный код для поиска вредоносной активности.
* **Имя нового процесса** — что запустили (например, `C:\Windows\System32\cmd.exe`).
* **Командная строка процесса** — с какими аргументами (например, `mimikatz.exe sekurlsa::logonpasswords full`).
* **Имя процесса-создателя** (Parent PID) — кто родитель.
* **ИД нового процесса (PID)** — идентификатор.
* **ИД процесса-создателя (PPID)** — идентификатор родителя.

Логика: если `cmd.exe` (родитель) запускает `powershell.exe` с длинной обфусцированной строкой — это подозрительно. Если `explorer.exe` запускает `notepad.exe` — это норма.

### Доступ к файлам и реестру

**4656 — Запрошен дескриптор объекта**
Кто-то просит доступ к объекту (файлу, папке, процессу).
* **Имя объекта** — к чему лезут.
* **Имя процесса** — кто лезет.
* **Операции доступа** — что хотят делать (чтение, запись, выполнение).

**4663 — Попытка доступа к объекту**
Уже само действие (открыл, прочитал, изменил).
* Если `mimikatz.exe` лезет к `lsass.exe` — это попытка кражи паролей.
* Если `notepad.exe` открывает `info.txt` — это просто блокнот.

**4657 — Значение реестра изменено**
Кто и что поменял в реестре. Полезно для поиска автозагрузки.

**1102 — Журнал аудита очищен**
Красный флаг. Злоумышленник заметает следы. Смотреть на **Субъект** (кто очистил) — обычно `dryabyshkin_adm` или `SYSTEM`.

### Службы и политики

**7045 — Установлена новая служба**
Злоумышленник закрепляется в системе через службу. Смотреть на **Имя службы** и **Путь к исполняемому файлу**.

**4697 — Установлена служба (Security)**
Аналог 7045, но в журнале Безопасность.

**4698 — Создано задание в планировщике**
Закрепление через Task Scheduler.

**4720 — Создана учетная запись**
Кто-то создал нового пользователя. Если это не админ — красный флаг.

**4732 — Пользователь добавлен в группу**
Например, в группу "Администраторы". Проверять, кого добавили.

## Как искать: практические приемы

**Фильтр по коду**
1. Правой кнопкой на журнале «Безопасность» -> **Фильтр текущего журнала**.
2. В поле **«Коды событий»** вводишь нужный код (например, `4624` или `4688`).
3. Нажимаешь ОК.

**Поиск по ключевому слову**
В правой панели есть **«Найти»** (или `Ctrl + F`). Ищешь по имени процесса (`mimikatz`), по IP, по имени учетки (`dryabyshkin_adm`).

**Поиск по командной строке**
Если включен аудит (GPO: «Включить аудит создания процесса»), то в 4688 будет поле **«Командная строка процесса»**. Там видно аргументы запуска — самый ценный источник.

## Важно

1. **Event ID 4688** Именно там видно, какую утилиту запустил злоумышленник (`mimikatz`, `hashcat`, `whoami`, `cmd.exe`).
2. **Event ID 4625** Много неудачных входов с одного IP = атака.
3. **Event ID 1102** Если журнал очищен, значит, злоумышленник уже внутри.
4. **Связка PID и PPID.** По PID процесса (`0x21450`) находишь процесс (`whoami.exe`). По PPID (`0x58cc`) находишь родителя (`cmd.exe`). Так строится цепочка атаки.
5. **Logon ID** Идентификатор сессии. По нему можно связать все события одного пользователя (запуск процессов, доступ к файлам) в одну картину.
