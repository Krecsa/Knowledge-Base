# Процессы Windows

В операционной системе Windows у каждого процесса есть уникальный идентификатор **PID (Process ID)**. Он присваивается динамически и переиспользуется системой после завершения процесса, поэтому искать малварь только по PID бесполезно.

Ключ к детектированию скрытых угроз лежит в **PPID (Parent Process ID)**, то есть в номере родительского процесса. В нормальной Windows существует строгая иерархия (дерево процессов). Злоумышленники часто используют технику **PPID Spoofing** (подмену родителя), чтобы вредоносный процесс выглядел как легитимный. Например, `powershell.exe` с родителем `explorer.exe` выглядит нормально, а вот `powershell.exe`, запущенный из `winword.exe`, это уже подозрительно и может указывать на работу вредоносного макроса.

## Карта нормальных процессов
Чтобы видеть отклонения, нужно знать, как выглядит норма.
* **System (PID 4)** - это ядро, его родитель **System Idle Process (0)**.
* **smss.exe** - родитель System, создает сессии.
* **csrss.exe** и **wininit.exe** - родитель smss.exe. (Сам smss.exe завершается, поэтому в диспетчере родитель может быть не виден).
* **services.exe** - Диспетчер служб, родитель wininit.exe.
* **lsass.exe** - родитель wininit.exe. Отвечает за аутентификацию. Должен быть только в одном экземпляре.
* **svchost.exe** - родитель всегда **services.exe**. В командной строке всегда присутствует флаг `-k`.
* **explorer.exe** - запускается от имени пользователя (а не SYSTEM). Родитель - `userinit.exe`, который после запуска завершается.

## Наиболее часто используемые злоумышленниками процессы (LOLBins)
Техника Living off the Land (LOLBins) задействует легитимные процессы Windows для своих целей. Если `cmd.exe` запущен из `winword.exe` (Word), это почти наверняка атака через макрос.
**rundll32.exe**: легитимный процесс для запуска DLL-библиотек. Злоумышленники используют его для запуска вредоносных DLL, чтобы обойти антивирус (DLL Injection).
**svchost.exe**: любимый процесс для маскировки. Если `svchost.exe` лезет в интернет на странный IP, проверь его PPID. Если родитель не `services.exe`, это малварь.

## Поиск скрытых процессов
Обычный список процессов (через Диспетчер задач или команду `tasklist`) может не показывать скрытые угрозы. Рутткиты используют технику **DKOM (Direct Kernel Object Manipulation)**, чтобы выкусить процесс из списка ядра, делая его невидимым для ОС.
Для поиска таких аномалий используют инструменты криминалистики (например, Volatility). Они сканируют саму оперативную память напрямую (плагин `psscan`), а не доверяют списку, который предоставляет операционная система.

## Как проверить подозрительный процесс
Для глубокого анализа лучше использовать утилиты **Process Explorer** (от Microsoft Sysinternals) или **Process Hacker**, так как они дают больше данных, чем стандартный Диспетчер задач.
Включи отображение колонки **Parent PID**, чтобы видеть цепочку запуска.
Найди подозрительный процесс и проверь его **Command Line** (командную строку). Если там длинная закодированная строка (Base64), это признак обфускации вредоносного кода.
Проверь **Path** (путь до файла). Если `svchost.exe` запущен не из папки `C:\Windows\System32`, а из временной папки `C:\Temp`, это стопроцентный признак вируса или руткита.
